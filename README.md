# Kelly's Giraffe Getaway Vol. 2: Return of the Hyena King

Kelly and Jinxy are back! Ram, swing and slurp across 10 painted savanna levels and 5 boss battles to save Gigi from Cackles the Hyena King. A free game from Peter's Arcade.

Play: https://ploug76.github.io/kellys-giraffe-getaway-vol-2/

Controls: swipe and hold anywhere to move, swipe up or JUMP to jump, ACTION for punch/kick, bonk, neck ram (double-tap), tongue, swing, and neck pound (DOWN+ACTION in the air). Controllers: stick/D-pad move, A jump, X/B action, Y ram, Start pause.

Original game: https://ploug76.github.io/kellys-giraffe-getaway/
